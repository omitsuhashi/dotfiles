# Triage Labels

| Canonical role | Label | 意味 |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer による評価待ち |
| needs-info | needs-info | 報告者からの追加情報待ち |
| ready-for-agent | ready-for-agent | 仕様が揃い、エージェントが実装可能 |
| ready-for-human | ready-for-human | 人による実装が必要 |
| wontfix | wontfix | 対応しない |

スキルが triage role を指定したら、この表の Label を使用する。
